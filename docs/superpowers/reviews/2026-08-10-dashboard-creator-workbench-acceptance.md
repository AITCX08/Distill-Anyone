## 验收结论

- 创建：预检后可选择逐作品 Markdown、蒸馏 Skill 和 RAG 分块，并能查看静态示例。默认目录可复用；单次目录需要本地校验令牌。
- 执行：标题与集数是主信息；下载阶段才显示字节、速度与 ETA；非下载阶段展示真实阶段与检查点；暂停、继续、取消与重试保持任务级语义。
- 交付：完成态显示完成时间、产物数量和产物入口。产物库按安全标题展示文件类型、大小、时间，并能在当前本地会话中查看任务保存位置或请求系统打开该位置。
- 可访问性与响应式：主导航语义化、激活页可识别；关键控件保留焦点环；操作目标最小高度为 44px；窄屏使用单列/横向可滚动导航。

## 隐私与脱敏核对

- Dashboard 只绑定 `127.0.0.1`。
- Cookie、二维码载荷、凭据、命令行、PID 和原始 Worker 输出不进入浏览器、SSE、事件或文档示例。
- 默认目录和任务覆盖目录属于私有配置；任务列表、SSE 快照、实时日志和错误文本均不展示绝对路径。
- 绝对保存目录仅在当前本地会话保护的任务详情和产物页面中显示；打开目录接口只使用服务端保存的任务白名单目录，不接受客户端路径。
