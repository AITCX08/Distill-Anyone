# 系列作品轨道视觉设计

## 目标

将任务作战台中的系列编号控件从紧凑的数字按钮组改为可读的作品进度轨道，使用户无需逐个查看作品表格即可辨认完成、执行中、失败和等待状态。

## 设计决策

- 保留现有 `SeriesRail` 输入、点击选择行为和可访问名称，不增加 API 或状态字段。
- 节点按作品顺序用细连接线串联；完成节点使用青绿色实心圆与对勾，执行中节点使用青色强调环，失败节点使用红色，等待节点使用低对比描边。
- 每个节点下方显示“第 N 集”；选中节点额外显示状态文本，避免状态仅靠颜色表达。
- 节点仍是原生按钮，保留 `aria-pressed`、键盘焦点与 `aria-label`；窄屏横向滚动，不挤压为难以点击的按钮。
- 不显示标题、BV 号、真实路径或其他任务数据；这些信息继续由下方作品表负责展示。

## 布局与响应式

- 桌面端轨道在任务总览下方横向铺开，节点最小可点击尺寸为 40px。
- 轨道连接线位于节点中心高度，最后一个节点后不绘制延伸线。
- 视口较窄时容器允许横向滚动，并保留首尾内边距；节点和文字不换行压缩。
- 使用现有深色青蓝令牌、Fluent UI 字体与 `:focus-visible` 样式；动画仅限低成本色彩与边框变化，遵从 `prefers-reduced-motion`。

## 验收

- 1–8 不再呈现为默认分页样式，而是明确的连续进度轨道。
- 已完成、执行中、失败、等待和选中状态都同时有文字或可访问语义。
- 点击节点仍会调用原有 `onSelect(rowId)`；既有 `aria-pressed` 行为不变。
- `SeriesRail` 测试、TypeScript 检查和相关 Dashboard 构建通过。
