# 旧系列任务恢复与历史详情实施计划

> **供执行代理使用：** 必须使用 `superpowers:executing-plans` 串行执行；每个任务都遵循测试先行并在独立小提交后继续。

**目标：** 修复旧 B 站系列执行器的假运行状态，并为历史页补齐每集标题和私有交付详情。

**架构：** 保持 `SeriesTaskBridge` 作为旧状态到标准 `JobState` 的适配层。以运行器存活探针决定恢复行为；标题由项目接口传输，路径仅由现有本地会话保护的详情接口返回。

**技术栈：** Python 3、FastAPI、React、TypeScript、Vitest。

## 全局约束

- 所有用户可见文案和 Markdown 文档使用简体中文。
- 目录路径不得进入任务列表、SSE 事件、运行日志或错误消息。
- Windows 上 Python 测试只能通过 `scripts/run-pytest-background.cmd` 的无窗口包装器运行。
- 恢复不得重跑已完成作品。
