# 平台支持与故障排查

## 支持矩阵

| 能力 | Windows | macOS | 说明 |
| --- | --- | --- | --- |
| CLI 与本地 Dashboard | 正式支持 | 正式文档支持、基础 CI 覆盖 | Dashboard 只监听 `127.0.0.1`。 |
| Dashboard 启动 | 使用隐藏启动方式 | 使用前台 `python main.py dashboard --port 8765 --no-open` | 不要将服务暴露到局域网或公网。 |
| Python 基础回归 | 正式支持 | macOS CI 离线基础用例 | macOS CI 不下载媒体、不调用外部模型。 |
| Bilibili / 抖音扫码 | 需在本机设备验收 | 需要设备验收 | 登录凭据不会返回到 Dashboard、SSE 或日志。 |
| Playwright 浏览器 | 已在 Windows 工作流使用 | 需要设备验收 | 安装 Chromium 后再执行真实平台操作。 |
| FunASR Apple Silicon MPS | 不适用 | 需要设备验收 | 未承诺与 CUDA/CPU 相同的稳定性或性能。 |

“正式文档支持”表示安装、启动、排障与 CI 基础路径已维护；并不表示所有第三方平台、扫码流程、浏览器自动化和硬件加速都已经在真实 macOS 设备上完成验收。

## 安装与依赖检查

在 macOS 的 zsh 中：

```zsh
python3 --version
brew --version
brew install ffmpeg
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m playwright install chromium
```

开发 Dashboard 时还需要 Node.js 24：

```zsh
node --version
cd dashboard
npm ci
```

若 `ffmpeg` 或 Node 不在 `PATH` 中，先修正 shell 配置后重新打开终端，再继续安装。不要将系统路径、浏览器 profile、Cookie 或 `.env` 内容粘贴到公开 issue。

## 启动与健康检查

macOS 使用前台进程启动，方便在终端中观察错误：

```zsh
python main.py dashboard --port 8765 --no-open
```

另开一个终端确认服务：

```zsh
curl http://127.0.0.1:8765/api/v1/health
```

响应中的 `status` 应为 `ok`，`static_compatible` 应为 `true`。浏览器访问 `http://127.0.0.1:8765/` 即可打开界面。

Windows 的隐藏启动与后台测试规则只适用于其专用说明；macOS 不需要也不应使用这些 Windows 专用机制。

## 常见问题

### 端口 8765 已被占用

可改用其他未占用端口，例如：

```zsh
python main.py dashboard --port 9000 --no-open
```

然后访问对应的本地地址。若需要定位占用进程，只记录进程名称和端口；不要在公开渠道提交完整终端历史。

### Playwright 或 Chromium 安装失败

先确保虚拟环境已激活，再重新执行 `python -m playwright install chromium`。公司网络、代理配置或系统安全策略都可能阻止浏览器下载。安装成功不等于 Bilibili 或抖音扫码流程已完成设备验收。

### Finder 或 Explorer 没有打开产物目录

Dashboard 只能打开当前任务已经授权的本地保存位置。确认任务已完成、产物存在，并检查系统是否阻止应用打开文件管理器。不要尝试把保存目录改为网络共享或公开可访问的位置。

### macOS 上的真实扫码或 Apple Silicon ASR

这两类流程需要实际设备验收。遇到问题时，请提供版本号、macOS 版本、芯片类型、脱敏后的错误摘要和可复现步骤；不要提供二维码、Cookie、浏览器 profile、API Key、媒体文件或完整 Worker 日志。

## 提交脱敏问题报告

问题报告至少应包含：项目版本或提交号、操作系统版本、Python/Node 版本、最短复现步骤、预期行为、实际行为和脱敏错误摘要。请先阅读 [SECURITY.md](../SECURITY.md)；安全问题不要公开提交。
