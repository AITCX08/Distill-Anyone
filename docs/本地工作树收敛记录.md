- 旧主工作树的 `main` 与 `origin/main` 已产生双向分叉：本地存在独有提交，同时也落后于远端发布历史。

### 采取的保护措施

- 已从旧主工作树当前提交创建保护分支：`backup/pre-release-main-20260812`。
- 保留原有 stash：`stash@{0}: preserve-local-pre-distill-everything-sync`。
- 未执行 `git reset --hard`、`git clean` 或 `git stash drop`，也未移动旧主工作树中的任何用户内容。
